Window & frame extraction

Splitting a waveform into overlapping frames and pre-processing each frame (dithering, DC offset removal, preemphasis, windowing) before the FFT (kaldi-native-fbank/csrc/feature-window.h). kaldi counterpart: FrameExtractionOptions. See Python API reference for the full field-by-field mapping to kaldi options.

Every feature extractor accepts these settings via its frame_opts field. The window formulas for each window_type are documented on kaldi_native_fbank.FrameExtractionOptions() (and in the C++ docs).

import kaldi_native_fbank as knf

opts = knf.FrameExtractionOptions()
opts.samp_freq = 16000
opts.dither = 0  # deterministic output

window = knf.FeatureWindowFunction(opts)
frame = [0.0] * len(window.window)  # one frame of window_size
windowed = window.apply(frame)

Options for extracting frames from a waveform.

This is the equivalent of kaldi's FrameExtractionOptions. It controls how a waveform is split into overlapping frames and how each frame is pre-processed (dithering, DC offset removal, preemphasis, windowing) before the FFT.

property window_type

Window type: one of "hanning", "hann", "sine", "hamming", "povey", "rectangular" or "blackman".

Let \(N\) be the window size, \(n = 0, \ldots, N-1\) the sample index, and \(a = 2\pi/(N-1)\). The formulas are:

  • "hanning": \(w[n] = 0.5 - 0.5 \cos(a n)\)

  • "hann": \(w[n] = 0.5 - 0.5 \cos(a n)\) with \(a = 2\pi/N\) (periodic variant; see the hann_window docs of PyTorch)

  • "sine": \(w[n] = \sin(0.5\,a\,n) = \sin(\pi n/(N-1))\)

  • "hamming": \(w[n] = 0.54 - 0.46 \cos(a n)\)

  • "povey": \(w[n] = (0.5 - 0.5 \cos(a n))^{0.85}\) (like hamming but goes to zero at the edges)

  • "rectangular": \(w[n] = 1\)

  • "blackman": \(w[n] = c - 0.5 \cos(a n) + (0.5 - c) \cos(2 a n)\) where \(c\) is blackman_coeff.
