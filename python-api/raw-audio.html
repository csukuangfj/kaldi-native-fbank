Raw audio framing

Frame raw waveform samples without any processing — no dithering, preemphasis, DC offset removal or windowing (kaldi-native-fbank/csrc/feature-raw-audio-samples.h). This is useful for models that consume raw waveform chunks and want the same streaming interface as the feature extractors. There is no kaldi counterpart.

import numpy as np
import kaldi_native_fbank as knf

opts = knf.RawAudioSamplesOptions()
framer = knf.OnlineRawAudioSamples(opts)

framer.accept_waveform(16000, samples)
framer.input_finished()
chunk = framer.get_frame(0)  # (dim,) raw samples of the first frame

class kaldi_native_fbank.RawAudioSamplesOptions(self: kaldi_native_fbank.RawAudioSamplesOptions, frame_opts: kaldi_native_fbank.FrameExtractionOptions = RawAudioSamplesOptions().frame_opts)

Options for framing raw audio samples without any processing.

The default frame_opts performs no processing on the samples: rectangular window, no dithering, no preemphasis, no DC offset removal, no zero-padding.

See also
