STFT / iSTFT

Short-time Fourier transform and its inverse (kaldi-native-fbank/csrc/stft.h, kaldi-native-fbank/csrc/istft.h).

import kaldi_native_fbank as knf

config = knf.StftConfig(...)
stft = knf.Stft(config)
spec = stft(samples)          # complex spectra
istft = knf.IStft(config)
wave = istft(spec)

Note: these are low-level signal-processing building blocks (as used inside kaldi's pitch tracker etc.); there is no direct kaldi binary counterpart — kaldi implements STFT inside feature extraction.

  • n_fft -- FFT size; should be a power of two.

  • hop_length -- Number of samples between successive frames.

  • win_length -- Window size in samples (must be <= n_fft).

property center

If True, pad the signal by n_fft // 2 on both sides (using pad_mode) and center the frames.

property hop_length

FFT size; should be a power of two.

property normalized

If True, scale the FFT by 1 / sqrt(n_fft).

Padding mode used when center is True; currently only "reflect".

Window size in samples; must be <= n_fft. The window is zero-padded to n_fft.

Window type, e.g. "hann"; ignored if explicit window coefficients are given.

class kaldi_native_fbank.IStft(self: kaldi_native_fbank.IStft, config: kaldi_native_fbank.StftConfig)

Reconstruct a waveform from Stft results.

This is the inverse of Stft (compatible with librosa's istft()): the frames are inverse-transformed, windowed, overlap-added, and divided by the summed window envelope.

class kaldi_native_fbank.Rfft(self: kaldi_native_fbank.Rfft, n: SupportsInt, inverse: bool = False)

n-point real discrete Fourier transform, where n is even.

Forward transform:

\[ \begin{align}\begin{aligned}R[k] = \sum_{j=0}^{n-1} \mathrm{in}[j] \cos(2\pi j k / n), \quad 0 \le k \le n/2\\I[k] = \sum_{j=0}^{n-1} \mathrm{in}[j] \sin(2\pi j k / n), \quad 0 < k < n/2\end{aligned}\end{align} \]

See also

Stft

Construct for an n-point transform.

Parameters:

  • n -- Number of fft points; must be even and >= 2.

  • inverse -- If True, compute() performs the inverse transform.

compute(self: kaldi_native_fbank.Rfft, arg0: collections.abc.Sequence[SupportsFloat]) → list[float]

Transform in place and return the packed spectrum.

On return of the forward transform:

  • out[0] = R[0]

  • out[1] = R[n/2]

  • for 1 < k < n/2: out[2*k] = R[k], out[2*k+1] = I[k]

Parameters:

d -- 1-D list of n floats.

Returns:

The packed spectrum, a 1-D list of n floats.
