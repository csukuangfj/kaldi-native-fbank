Pitch

Pitch extraction — the equivalent of kaldi's compute-and-process-kaldi-pitch-feats (kaldi-native-fbank/csrc/feature-pitch.h, pitch-functions), implementing "A Pitch Extraction Algorithm Tuned for Automatic Speech Recognition", Ghahremani et al., ICASSP 2014.

The extractor downsamples the waveform, evaluates the normalized cross-correlation function (NCCF) at log-spaced lags between \(1/\mathrm{max\_f0}\) and \(1/\mathrm{min\_f0}\), picks a per-frame lag with a Viterbi search, and post-processes the raw \((\mathrm{NCCF}, \mathrm{pitch})\) pair into the configured features — by default the 3-dimensional (POV-feature, normalized-log-pitch, delta-log-pitch) used by kaldi.

Batch usage (kaldi's compute-and-process-kaldi-pitch-feats):

import kaldi_native_fbank as knf

pitch_opts = knf.PitchExtractionOptions(min_f0=50, max_f0=500,
                                        snip_edges=True)
process_opts = knf.ProcessPitchOptions()  # 3-dim output
feats = knf.compute_and_process_kaldi_pitch(pitch_opts, process_opts,
                                            samples)  # (T, 3)

Streaming usage (same interface as kaldi_native_fbank.OnlineMfcc):

pitch = knf.OnlinePitch(pitch_opts, process_opts)
pitch.accept_waveform(16000, samples)
pitch.input_finished()
for t in range(pitch.num_frames_ready):
    frame = pitch.get_frame(t)  # np.ndarray of shape (3,)

Sample scale: feed samples at raw int16 amplitude (do not divide by 32768); kaldi's wav reader keeps raw magnitudes.

Determinism: the noise added to the delta-pitch feature (delta_pitch_noise_stddev) is drawn from a deterministic stream that reproduces the reference kaldi realization, so features are identical on every platform (and match the golden test data in tests/data/feat_golden).

Determines which features are produced from the raw (NCCF, pitch) pair. With the defaults each frame is the 3-dimensional (POV-feature, normalized-log-pitch, delta-log-pitch) output of kaldi's compute-and-process-kaldi-pitch-feats; see kaldi's ProcessPitchOptions.

class kaldi_native_fbank.OnlinePitch(self: kaldi_native_fbank.OnlinePitch, opts: kaldi_native_fbank.PitchExtractionOptions, popts: kaldi_native_fbank.ProcessPitchOptions = ProcessPitchOptions())

Streaming pitch extraction with post-processing.

This is the streaming interface of kaldi's compute-and-process-kaldi-pitch-feats (kaldi's OnlinePitchFeature + OnlineProcessPitch): it consumes waveform chunks and produces the processed pitch features — by default the 3-dimensional (POV, normalized-log-pitch, delta-pitch).

Usage mirrors kaldi_native_fbank.OnlineMfcc: feed the waveform with accept_waveform(), call input_finished() when no more data is coming, then read frames with get_frame().

kaldi_native_fbank.compute_and_process_kaldi_pitch(pitch_opts: kaldi_native_fbank.PitchExtractionOptions, process_opts: kaldi_native_fbank.ProcessPitchOptions, wave: collections.abc.Sequence[SupportsFloat]) → Annotated[numpy.typing.NDArray[numpy.float32], '[m, n]']

Compute processed pitch features for a whole utterance.

This is kaldi's compute-and-process-kaldi-pitch-feats (same arithmetic): the raw (NCCF, pitch) extraction of Ghahremani et al., ICASSP 2014 followed by post-processing into the configured features (by default POV, normalized-log-pitch, delta-pitch). The output equals the kaldi binary's output value-by-value for the same input and options.

It is sensitive to the variables in pitch_opts that relate to online processing, i.e. max_frames_latency, frames_per_chunk, simulate_first_pass_online, recompute_frame.

The noise added to the delta-pitch feature (process_opts.delta_pitch_noise_stddev) is drawn from a deterministic stream that reproduces the reference kaldi realization, so the result is identical on every platform.

Parameters:

  • pitch_opts -- Raw pitch extraction options.

  • process_opts -- Post-processing options.

  • wave (numpy.ndarray) -- 1-D float32 samples (kaldi semantics: raw WAV magnitudes, not divided by 32768).

Returns:

Feature matrix of shape (num_frames, process_opts.dim), float32.

Return type:

numpy.ndarray

Example

import wave
import numpy as np
import kaldi_native_fbank as knf

with wave.open("zh0_1s.wav") as f:
    samples = np.frombuffer(f.readframes(f.getnframes()), dtype=np.int16)
samples = samples.astype(np.float32)  # raw magnitudes, no /32768

pitch_opts = knf.PitchExtractionOptions(min_f0=50, max_f0=500,
                                        snip_edges=True)
feats = knf.compute_and_process_kaldi_pitch(pitch_opts,
                                            knf.ProcessPitchOptions(),
                                            samples)
# feats.shape == (num_frames, 3): POV, norm-log-pitch, delta-pitch
