Mel filter banks

Triangular mel-frequency filter banks that project FFT bin energies onto mel bins (kaldi-native-fbank/csrc/mel-computations.h). kaldi counterpart: MelBanksOptions.

Both kaldi-style and librosa-style filters are supported (is_librosa=True). The MFCC/fbank extractors use these internally via mel_opts; you can also use them directly:

import numpy as np
import kaldi_native_fbank as knf

mel_opts = knf.MelBanksOptions(num_bins=23, low_freq=20, high_freq=7800)
frame_opts = knf.FrameExtractionOptions()
banks = knf.MelBanks(mel_opts, frame_opts)

weights = banks.get_matrix()          # (23, num_fft_bins // 2 + 1)
mel = banks.compute(power_spectrum)   # (23,) mel energies, not log

class kaldi_native_fbank.MelBanks(self: kaldi_native_fbank.MelBanks, opts: kaldi_native_fbank.MelBanksOptions = MelBanksOptions(), frame_opts: kaldi_native_fbank.FrameExtractionOptions = FrameExtractionOptions(), vtln_warp_factor: SupportsFloat = 1.0)

Triangular mel filter banks.

A MelBanks object holds the weights of a set of triangular mel-frequency bins and can project FFT bin energies onto them.

See also

MelBanksOptions

Construct kaldi-compatible (or librosa-style) mel banks.

The mel bin edges are placed uniformly on the mel scale between opts.low_freq and opts.high_freq; each bin is a triangle in the frequency domain. If opts.is_librosa is true, librosa-style filters are computed instead.

Parameters:

  • opts -- Mel-bin configuration; see MelBanksOptions.

  • frame_opts -- Frame-extraction configuration (provides samp_freq and the FFT size).

  • vtln_warp_factor -- VTLN warping factor (1.0 means no warping).

compute(self: kaldi_native_fbank.MelBanks, fft_energies: Annotated[numpy.typing.ArrayLike, numpy.float32]) → numpy.typing.NDArray[numpy.float32]

Compute mel energies (note: NOT log) from a power spectrum.

For each mel bin \(i\), the output is the weighted sum of the FFT bin energies that fall into that bin:

\[\mathrm{mel}[i] = \sum_{k} w[i][k] \cdot \mathrm{fft\_energies}[\mathrm{offset}[i] + k]\]

where \(\mathrm{offset}[i]\) is the first nonzero fft bin of mel bin \(i\) and \(w[i]\) are its triangle weights.

Parameters:

fft_energies -- 1-D float32 array of size num_fft_bins // 2 + 1 holding the power spectrum (not log). Must be C-contiguous.

Returns:

1-D float32 array of size num_mel_bins with the mel energies.

get_matrix(self: kaldi_native_fbank.MelBanks) → numpy.typing.NDArray[numpy.float32]

Return the mel filter weights.

Returns:

A float32 array of shape (num_mel_bins, num_fft_bins // 2 + 1); weights[i, k] is the weight of fft bin \(k\) for mel bin \(i\).
