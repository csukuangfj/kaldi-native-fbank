NeMo filter bank

NeMo-compatible buffered streaming filter-bank features (kaldi-native-fbank/csrc/online-nemo-fbank.h). NeMo buffered streaming re-featurizes each requested audio window: preemphasis, then a centered constant-zero-padded STFT, a symmetric Hann window, Slaney mel filters and \(\log(\mathrm{mel} + 2^{-24})\).

Input samples are floats in [-1, 1]; the class does not resample or normalize. There is no direct kaldi binary counterpart — this reproduces NeMo's streaming feature extraction.

import numpy as np
import kaldi_native_fbank as knf

opts = knf.NemoFbankOptions(num_mel_bins=80)
fbank = knf.OnlineNemoFbank(opts)

fbank.accept_waveform(16000, samples)   # samples in [-1, 1]
fbank.input_finished()
frames, offset = fbank.get_frames(0, fbank.num_frames_ready, is_final=True)

class kaldi_native_fbank.OnlineNemoFbank(self: kaldi_native_fbank.OnlineNemoFbank, opts: kaldi_native_fbank.NemoFbankOptions)

NeMo-compatible buffered streaming filter-bank features.

NeMo buffered streaming re-featurizes each requested audio window: preemphasis over that window, then a centered, constant-zero-padded STFT, a symmetric Hann window, Slaney mel filters, and \(\log(\mathrm{mel} + 2^{-24})\). Input samples are floats in [-1, 1]. This class does not resample or normalize.

get_frames(self: kaldi_native_fbank.OnlineNemoFbank, frame_index: SupportsInt, n: SupportsInt, is_final: bool = False) → tuple

Return n frames starting at the absolute frame_index.

Samples preceding the requested window are discarded; later calls cannot rewind. If is_final reaches the last ready frame after input_finished(), the partial hop is included. When n equals buffered_capacity, the window is capped at n hops by shifting its start by the remainder; that shift (in samples) is reported as the second element of the returned tuple.

Parameters:

  • frame_index -- Absolute index of the first frame to return.

  • n -- Number of frames.

  • is_final -- True if this is the final request.

Returns:

A tuple (frames, start_sample_offset) where frames is a float32 array of shape (n, dim) and start_sample_offset is 0 unless the buffer cap shifted the window.
