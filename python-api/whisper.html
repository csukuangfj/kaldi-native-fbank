Whisper Fbank

Whisper-style log-mel features (kaldi-native-fbank/csrc/whisper-feature.h).

import kaldi_native_fbank as knf

opts = knf.WhisperFeatureOptions()
f = knf.OnlineWhisperFbank(opts)
f.accept_waveform(16000, samples)
f.input_finished()
frame = f.get_frame(0)

Note: whisper features follow OpenAI Whisper's front-end, not kaldi; there is no kaldi binary counterpart to compare against.

API reference

class kaldi_native_fbank.WhisperFeatureOptions(self: kaldi_native_fbank.WhisperFeatureOptions, frame_opts: kaldi_native_fbank.FrameExtractionOptions = FrameExtractionOptions(), dim: SupportsInt = 80)

Options for computing Whisper mel features.

Note that most fields of frame_opts are ignored and reset inside WhisperFeatureComputer: 16 kHz sampling rate, 25 ms window, 10 ms shift, "hann" window, snip_edges=False, etc.
