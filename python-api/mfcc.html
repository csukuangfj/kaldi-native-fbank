MFCC

Mel-frequency cepstral coefficients, kaldi-compatible (kaldi-native-fbank/csrc/feature-mfcc.h). Numerically equal to kaldi's compute-mfcc-feats for identical parameters.

Usage

import numpy as np
import kaldi_native_fbank as knf

samples = ...  # 1-D float32 waveform, raw int16 amplitude scale
sample_rate = 16000

opts = knf.MfccOptions()
opts.frame_opts.samp_freq = sample_rate
opts.frame_opts.snip_edges = True
opts.frame_opts.dither = 0.0          # use 0 for deterministic output
opts.mel_opts.num_bins = 23
opts.mel_opts.low_freq = 20
opts.mel_opts.high_freq = 7800
opts.num_ceps = 13
opts.use_energy = False
opts.cepstral_lifter = 22

mfcc = knf.OnlineMfcc(opts)
mfcc.accept_waveform(sample_rate, samples)
mfcc.input_finished()
num_frames = mfcc.num_frames_ready
frame = mfcc.get_frame(0)             # list of floats, dim = num_ceps

Important: feed samples at raw int16 amplitude (do NOT divide by 32768). kaldi's wav reader keeps raw magnitudes; normalizing scales the energy by 32768^2 and shifts C0.

Equivalent in kaldi

# kaldi (dither off for deterministic output)
compute-mfcc-feats --dither=0.0 --use-energy=false --num-ceps=13 \\
  --num-mel-bins=23 --cepstral-lifter=22 --low-freq=20 --high-freq=7800 \\
  --sample-frequency=16000 --snip-edges=true scp:wav.scp ark:mfcc.ark

With dither=0 and identical parameters the output matches kaldi value-by-value (verified against compute-mfcc-feats output; residual diff ~1e-4 at float rounding level).

  • num_ceps -- Number of cepstra in the MFCC computation (including C0).

  • energy_floor -- Absolute floor on energy (only with use_energy; needed when dither is 0).

  • raw_energy -- Compute energy before preemphasis/windowing.

  • cepstral_lifter -- Liftering constant; 0 disables liftering.

as_dict(self: kaldi_native_fbank.MfccOptions) → dict

Return the options as a dict.

property cepstral_lifter

Constant that controls scaling of the MFCCs (liftering). If 0.0, no liftering is done.

property energy_floor

Floor on energy (absolute, not relative). Only makes a difference if use_energy is True; only necessary if frame_opts.dither is 0. Suggested values: 0.1 or 1.0.

property frame_opts

Frame-extraction options; see FrameExtractionOptions.

static from_dict(arg0: dict) → kaldi_native_fbank.MfccOptions

Build options from a dict.

property htk_compat

If True, put energy/C0 last and use a factor of sqrt(2) on C0. Warning: not sufficient for HTK-compatible features (other parameters must change too).

property mel_opts

Mel filter-bank options; see MelBanksOptions. The default has 23 mel bins.

property num_ceps

Number of cepstra in the MFCC computation (including C0).

property raw_energy

If True, compute energy before preemphasis and windowing.

property use_energy

Use energy (not C0) in the MFCC computation.
