Detailed Description

Resample a signal at arbitrary (e.g.

log-spaced) time points.

Class ArbitraryResample allows you to resample a signal (assumed zero outside the sample region, not periodic) at arbitrary specified time values, which don't have to be linearly spaced. The low-pass filter cutoff filter_cutoff_hz should be less than half the sample rate; num_zeros should probably be at least two preferably more; higher numbers give sharper filters but will be less efficient.

Used by:
OnlinePitch resamples the NCCF from evenly spaced lags to the log-spaced lags at which pitch is measured.
