Detailed Description

Triangular mel-filterbank bins.

A MelBanks object holds the weights of a set of triangular mel-frequency bins and can project FFT bin energies onto them. See also https://en.wikipedia.org/wiki/Mel_scale

Used by:
FbankComputer, MfccComputer, WhisperFeatureComputer, and OnlineNemoFbank.
See also
MelBanksOptions, FbankComputer, MfccComputer, ComputeLifterCoeffs

Construct kaldi-compatible mel banks.

The mel bin edges are placed uniformly on the mel scale between opts.low_freq and opts.high_freq; each bin is a triangle in the frequency domain, defined by a start fft bin and per-bin weights (see GetBins()/GetMatrix()). If opts.is_librosa is true, librosa-style filters are computed instead.

Parameters
[in]optsMel-bin configuration; see MelBanksOptions.
[in]frame_optsFrame-extraction configuration (provides samp_freq and the FFT size).
[in]vtln_warp_factorVTLN warping factor (1.0 means no warping); the bin edges are warped with VtlnWarpMelFreq() before the triangles are computed.

◆ Compute()

void knf::MelBanks::Compute ( const float * fft_energies,
float * mel_energies_out ) const

Compute mel energies (note: NOT log energies).

At input, "fft_energies" contains the FFT energies (not log). For each mel bin \( i \), the output is the weighted sum of the FFT bin energies that fall into that bin:

\[ \mathrm{mel\_energies\_out}[i] = \sum_{k} w[i][k] \cdot \mathrm{fft\_energies}[\mathrm{offset}[i] + k] \]

where \( \mathrm{offset}[i] \) is the first nonzero fft bin of mel bin \( i \) and \( w[i] \) are its triangle weights.

Parameters
[in]fft_energies1-D array of size num_fft_bins/2+1, holding the power spectrum (not log).
[out]mel_energies_out1-D array of size num_mel_bins; the caller must pre-allocate it. On return it holds the mel energies (not log).

Piecewise-linear VTLN warping function in the frequency domain.

This computes a VTLN warping function that is not the same as HTK's one, but has similar inputs (this function has the advantage of never producing empty bins).

This function computes a warp function \( F(\mathrm{freq}) \), defined between low_freq and high_freq inclusive, with the following properties:

  • \( F(\mathrm{low\_freq}) = \mathrm{low\_freq} \)
  • \( F(\mathrm{high\_freq}) = \mathrm{high\_freq} \)

The function is continuous and piecewise linear with two inflection points. The lower inflection point (measured in terms of the unwarped frequency) is at frequency \( l \); the higher inflection point is at a frequency \( h \). If \( l \le f \le h \), then \( F(f) = f/\mathrm{vtln\_warp\_factor} \).

If the higher inflection point (measured in terms of the unwarped frequency) is at \( h \), then \( \max(h, F(h)) = \mathrm{vtln\_high\_cutoff} \). Since \( F(h) = h/\mathrm{vtln\_warp\_factor} \), then \( \max(h, h/\mathrm{vtln\_warp\_factor}) = \mathrm{vtln\_high\_cutoff} \), so

\[ h = \frac{\mathrm{vtln\_high\_cutoff}} {\max(1,\, 1/\mathrm{vtln\_warp\_factor})} = \mathrm{vtln\_high\_cutoff} \cdot \min(1,\, \mathrm{vtln\_warp\_factor}). \]

If the lower inflection point (measured in terms of the unwarped frequency) is at \( l \), then \( \min(l, F(l)) = \mathrm{vtln\_low\_cutoff} \). This implies that

\[ l = \frac{\mathrm{vtln\_low\_cutoff}} {\min(1,\, 1/\mathrm{vtln\_warp\_factor})} = \mathrm{vtln\_low\_cutoff} \cdot \max(1,\, \mathrm{vtln\_warp\_factor}). \]

Parameters
[in]vtln_low_cutoffLower discontinuity of the warp function; must be > low_freq.
[in]vtln_high_cutoffUpper discontinuity of the warp function; must be < high_freq.
[in]low_freqLower frequency cutoff of the mel computation.
[in]high_freqUpper frequency cutoff of the mel computation.
[in]vtln_warp_factorVTLN warping factor (1.0 means no warping).
[in]freqThe frequency to warp.
Returns
The warped frequency; freq itself if it lies outside [low_freq, high_freq].

Piecewise-linear VTLN warping function in the mel domain.

Same as VtlnWarpFreq(), but the input and output are on the mel scale: it warps mel_freq by first converting it to Hz, applying VtlnWarpFreq(), and converting the result back to mel.
