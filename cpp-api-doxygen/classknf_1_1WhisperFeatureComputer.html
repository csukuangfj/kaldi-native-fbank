Detailed Description

Class for computing Whisper mel features.

For each frame it computes the power spectrum and projects it onto librosa-style mel filter banks, producing mel power energies (not log).

Used by:
OnlineWhisperFbank = OnlineGenericBaseFeature<WhisperFeatureComputer> (see online-feature.h).
See also
WhisperFeatureOptions, MelBanks, OnlineWhisperFbank
