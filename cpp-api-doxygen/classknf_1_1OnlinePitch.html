Detailed Description

Streaming pitch extraction with post-processing (kaldi's OnlinePitchFeature + OnlineProcessPitch).

This is the streaming interface of kaldi's compute-and-process-kaldi-pitch-feats: it consumes waveform chunks and produces the processed pitch features (by default 3-dimensional: POV, normalized-log-pitch, delta-pitch).

Usage mirrors OnlineMfcc: feed the waveform with AcceptWaveform(), call InputFinished() when no more data is coming, then read frames with GetFrame(). Frames may become available before InputFinished() (with latency: see normalization_right_context and max_frames_latency), and InputFinished() flushes the remainder.

Features for a given frame may be revised as more data arrives (the Viterbi traceback and the normalization window settle over time), except for the delta-pitch noise which is drawn once per frame. After InputFinished(), the features are final and stable.

Used by:
Batch extraction via ComputeAndProcessKaldiPitch; MFA-style feature pipelines that append pitch to MFCC (paste-feats).
See also
PitchExtractionOptions, ProcessPitchOptions, ComputeAndProcessKaldiPitch, OnlineMfcc
