Detailed Description

n-point real discrete Fourier transform, where n is even, n >= 2.

Forward transform:

\[ R[k] = \sum_{j=0}^{n-1} \mathrm{in}[j] \cos(2\pi j k / n), \qquad 0 \le k \le n/2 \]

\[ I[k] = \sum_{j=0}^{n-1} \mathrm{in}[j] \sin(2\pi j k / n), \qquad 0 < k < n/2 \]

Used by:
FbankComputer, MfccComputer, Stft and IStft.
See also
ComputePowerSpectrum, Stft
