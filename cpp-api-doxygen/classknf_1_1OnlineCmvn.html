Detailed Description

Online (running) cepstral mean and optional variance normalization.

A port of kaldi's OnlineCmvn (kaldi/src/feat/online-feature.h), push-style: feed raw feature frames one by one and get the normalized frames back (kaldi's version is a pull-style filter in an OnlineFeatureInterface chain).

Unlike the offline CMVN of feature-cmvn.h (which uses the whole utterance), this class looks only at the past. In the middle of a long utterance it accumulates stats from the previous cmn_window frames (default 600, i.e. 6 seconds) and normalizes the current frame with them. At the beginning of an utterance the window stats are augmented ("smoothed") with up to speaker_frames frames of speaker stats from previous utterances and up to global_frames frames of global stats, so the first frames are normalized against a reasonable distribution.

The frame being normalized is included in the stats that normalize it (exactly like kaldi). Variance normalization floors the variance at 1e-20.

Note
Features normalized this way are only approximately zero-mean, especially at utterance start. Acoustic models must be trained with the same kind of normalization ("matched" online training).
Parity with kaldi is tested frame-by-frame against apply-cmvn-online in tests/parity/parity_online_cmvn.py.

Example:

knf::OnlineCmvnOptions opts;
knf::OnlineCmvnState state(global_stats); // MatrixD [2, dim+1]
knf::OnlineCmvn cmvn(opts, state);
for (const knf::VectorF &f : frames) {
knf::VectorF y = cmvn.AcceptFeature(f);
}
auto next_state = cmvn.GetState(); // hand over to the next utterance

◆ Freeze()

void knf::OnlineCmvn::Freeze ( )

Freeze the normalization at the current frame.

From now on frames are normalized with the current (smoothed) stats and the running stats stop updating. The frozen state is part of GetState() so later utterances of the speaker keep the same normalization (kaldi uses this to estimate fMLLR on top of a fixed CMVN).

Smooth window stats with speaker and global stats.

A port of kaldi's static OnlineCmvn::SmoothOnlineCmvnStats. Adds up to speaker_frames worth of speaker stats and up to global_frames worth of global stats to stats, scaled by their counts, so the total count approaches cmn_window (a no-op once it is reached).

Parameters
speaker_stats[in] Speaker stats [2, dim+1], may be empty.
global_stats[in] Global stats [2, dim+1] (required at runtime).
opts[in] The options in use.
stats[in,out] Window stats to smooth.
