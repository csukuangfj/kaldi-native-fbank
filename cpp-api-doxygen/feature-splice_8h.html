Detailed Description

kaldi-native-fbank/kaldi-native-fbank/csrc/feature-splice.h

This file is part of kaldi-native-fbank.

Splice frames with their left/right context neighbors.

This is kaldi's splice-feats (see src/feat/feature-functions.cc): each output frame concatenates the input frame with left_context preceding and right_context following frames. Edge frames are replicated (a frame index below 0 clamps to 0 and an index past the end clamps to the last frame), so the output has the SAME number of frames as the input and dim * (1 + left_context + right_context) dimensions.

knf::SpliceOptions opts; // left_context=3, right_context=3
knf::MatrixF spliced = knf::SpliceFrames(feats, opts);
