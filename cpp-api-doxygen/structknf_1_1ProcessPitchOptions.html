Detailed Description

Options for the pitch post-processing stage (kaldi's ProcessPitchOptions).

Determines which features are produced from the raw (NCCF, pitch) pair. With the defaults, each frame is the 3-dimensional (POV-feature, normalized-log-pitch, delta-log-pitch) used by kaldi's compute-and-process-kaldi-pitch-feats; see src/feat/pitch-functions.h.

See also
OnlinePitch, ComputeAndProcessKaldiPitch

◆ delta_pitch_noise_stddev

float knf::ProcessPitchOptions::delta_pitch_noise_stddev = 0.005

Standard deviation for the noise we add to the delta log-pitch (before scaling); should be about the same as the delta_pitch option to pitch creation.

The purpose is to get rid of peaks in the delta-pitch caused by discretization of pitch values. (The noise is drawn from a deterministic stream — see ComputeAndProcessKaldiPitch — so the features are reproducible.) Kaldi --delta-pitch-noise-stddev.
