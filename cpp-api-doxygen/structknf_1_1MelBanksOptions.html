Detailed Description

Options for constructing triangular mel-filterbank bins.

The kaldi-compatible fields correspond to kaldi's MelBanksOptions (src/feat/mel-computations.h); the is_librosa-related fields select librosa-compatible filters instead.

Used by:
The mel_opts member of FbankOptions and MfccOptions, and the constructors of MelBanks.
See also
MelBanks, FbankOptions, MfccOptions

◆ is_librosa

bool knf::MelBanksOptions::is_librosa = false

If true, use librosa-style mel filters instead of kaldi-style ones.

Note that if you set is_librosa, you probably need to set low_freq to 0. See https://librosa.org/doc/main/generated/librosa.filters.mel.html
