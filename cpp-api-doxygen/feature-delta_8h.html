This file is part of kaldi-native-fbank.

Delta (dynamic) features.

This is kaldi's add-deltas (see src/feat/feature-functions.cc, class DeltaFeatures): each output frame concatenates the input features with their first- and second-order regression deltas, i.e. the output is [x, delta, delta-delta] with (order + 1) * dim dimensions.

knf::DeltaOptions opts; // order=2, window=2
knf::MatrixF out = knf::ComputeDeltas(opts, feats);
