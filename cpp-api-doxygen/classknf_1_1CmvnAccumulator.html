Detailed Description

Incremental accumulator for speaker-level / streaming cmvn.

It always keeps the full 2-row layout (see InitCmvnStats()) and adds up weighted frames one by one, so stats can be collected over many utterances of the same speaker and normalized later with ApplyCmvn().

Used by:
Pipelines that collect speaker-level stats incrementally (e.g. accumulate all utterances of a speaker, then normalize).
See also
AccCmvnStats, InitCmvnStats, ApplyCmvn
