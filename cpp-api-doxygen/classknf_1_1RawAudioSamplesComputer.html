Detailed Description

"Computer" that frames raw audio samples without any processing.

It has the same interface as FbankComputer/MfccComputer so it can be used with OnlineGenericBaseFeature (see online-feature.h).

Used by:
OnlineRawAudioSamples = OnlineGenericBaseFeature<RawAudioSamplesComputer> (see online-feature.h).
