◆ cepstral_lifter

float knf::MfccOptions::cepstral_lifter = 22.0

Constant that controls scaling of MFCCs (HTK liftering).

If 0.0, no liftering is done.

◆ energy_floor

float knf::MfccOptions::energy_floor = 0.0

Floor on energy (absolute, not relative) in MFCC computation.

Only makes a difference if use_energy is true; only necessary if frame_opts.dither is 0.0. Suggested values: 0.1 or 1.0.

bool knf::MfccOptions::htk_compat = false

If true, put energy or C0 last and use a factor of sqrt(2) on C0.
