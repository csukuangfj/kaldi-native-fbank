Detailed Description

template<class C>
class knf::OnlineGenericBaseFeature< C >

This is a templated class for online feature extraction; it's templated on a class like MfccComputer or FbankComputer that does the basic feature extraction.

Used by:
The aliases OnlineFbank, OnlineMfcc, OnlineWhisperFbank, and OnlineRawAudioSamples at the bottom of this file.
See also
FbankComputer, MfccComputer, WhisperFeatureComputer, RawAudioSamplesComputer, RecyclingVector
