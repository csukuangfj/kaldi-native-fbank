Detailed Description

A linear (or affine) feature transform, e.g.

an LDA matrix.

The transform is a matrix \( M \) of shape \( (D_{out} \times n) \); see the file description for the exact semantics, which follow kaldi's transform-feats (src/featbin/transform-feats.cc):

if \( n = D_{in} \) (the input feature dimension), the transform is linear: \( y = x\, M^{T} \); if \( n = D_{in} + 1 \), the transform is affine: the input features get an implicit 1.0 appended, so \( y = x\, M_{[:,\,0:n-1]}^{T} + M_{[:,\,n-1]} \); otherwise Apply() throws.

knf::FeatureTransform lda = knf::FeatureTransform::Read("lda.mat");
knf::MatrixF out = lda.Apply(feats);

◆ Apply() [2/2]

MatrixF knf::FeatureTransform::Apply ( const MatrixF & feats) const

Apply the transform to a feature matrix.

kaldi transform-feats semantics (rows = frames):

if the transform has feats.cols() columns, the output is \( Y = X M^{T} \) (linear); if it has feats.cols() + 1 columns, the transform is affine and the last column is the offset: \( Y = X M_{[:,\,0:n-1]}^{T} + \mathbf{1} b^{T} \); otherwise an exception is thrown.

Parameters

Returns

◆ IsAffine()

bool knf::FeatureTransform::IsAffine ( int32_t input_dim) const

True if the transform is affine for inputs of dimension input_dim.

The matrix alone cannot record the intended input dimension, so the rule is the one kaldi's transform-feats applies: the transform is affine iff it has one column more than the feature dimension ( \( n = D_{in} + 1 \)), the extra column being the offset.
