Detailed Description

Options for extracting frames from a waveform.

This struct is the equivalent of kaldi's FrameExtractionOptions (src/feat/feature-window.h).

Used by:
Every feature computer: it is the frame_opts member of FbankOptions, MfccOptions, WhisperFeatureOptions, RawAudioSamplesOptions, and it is also used by ExtractWindow()/ProcessWindow()/NumFrames().
See also
FeatureWindowFunction, ExtractWindow, NumFrames, FbankOptions

◆ snip_edges

bool knf::FrameExtractionOptions::snip_edges = true

If true, end effects are handled by outputting only frames that completely fit in the file, and the number of frames depends on the frame length.

If false, the number of frames depends only on the frame shift, and we reflect the data at the ends.

◆ window_type

std::string knf::FrameExtractionOptions::window_type = "povey"

Type of the windowing function; may be "hamming", "rectangular", "povey", "hanning", "hann", "sine", or "blackman".

"povey" is a window made to be similar to Hamming but to go to zero at the edges: \( w[n] = (0.5 - 0.5 \cos(2\pi n/(N-1)))^{0.85} \).
