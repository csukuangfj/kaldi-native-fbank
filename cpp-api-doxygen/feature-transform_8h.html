kaldi-native-fbank/kaldi-native-fbank/csrc/feature-transform.h

This file is part of kaldi-native-fbank.

Linear/affine feature transforms (e.g. LDA).

This is kaldi's transform-feats (see src/featbin/transform-feats.cc): it applies a stored matrix \( M \) of shape \( (D_{out} \times n) \) to feature rows \( x \) of dimension \( n \) (linear form) or \( n = D_{in}+1 \) (affine form, where the last column of \( M \) is an offset):

\[ y = x\, M^{T} \qquad\text{(linear)} \]

\[ y = x\, M_{[:,\,0:n-1]}^{T} + M_{[:,\,n-1]} \qquad\text{(affine)} \]

knf::FeatureTransform lda = knf::FeatureTransform::Read("lda.mat");
knf::MatrixF out = lda.Apply(feats); // (T, lda.OutputDim())
