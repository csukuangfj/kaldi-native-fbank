Detailed Description

kaldi-native-fbank/kaldi-native-fbank/csrc/feature-cmvn.h

This file is part of kaldi-native-fbank.

Cepstral mean and variance normalization (CMVN).

The semantics follow kaldi's src/transform/cmvn.cc exactly (same arithmetic and stats layout).

Cmvn stats layout (matches kaldi's cmvn.ark format exactly):

2-row stats (full stats, produced by InitCmvnStats/ComputeCmvnStats): row 0 = [sum_1 .. sum_D, count], row 1 = [sumsq_1 .. sumsq_D, (unused)]. Supports both mean and variance normalization.

1-row stats (mean-only stats; some pipelines only collect means): row 0 = [sum_1 .. sum_D, count]. Supports mean normalization only; requesting norm_vars with 1-row stats is an error (same as kaldi).

In both forms the frame count lives in the LAST column of row 0 (index dim); columns 0..dim-1 hold sums / sumsqs.
