Detailed Description

Stores the windowing coefficients and applies them to a frame.

The window type is specified either by a FrameExtractionOptions, by a window-type name plus a window size, or directly by the coefficients.

Used by:
ExtractWindow(), ProcessWindow(), Stft/IStft, and OnlineGenericBaseFeature (online-feature.h).
See also
GetWindow, FrameExtractionOptions, ProcessWindow
