Detailed Description

NeMo-compatible buffered streaming filter-bank features.

NeMo buffered streaming re-featurizes each requested audio window. Apply preemphasis over that window, then a centered, constant-zero-padded STFT, a symmetric Hann window, Slaney mel filters, and \( \log(\mathrm{mel} + 2^{-24}) \). Input samples are floats in [-1, 1]. This class does not resample or normalize. Like OnlineFbank, instances require external synchronization.

NemoFbankOptions, Stft, MelBanks, OnlineFbank

Return n row-major frames starting at the absolute frame_index.

Samples preceding the requested window are discarded; later calls cannot rewind. If is_final reaches the last ready frame after InputFinished(), include the partial hop. When n equals buffered_capacity, cap the window at n hops by shifting its start by the remainder. Report that shift (in samples) through start_sample_offset, which is otherwise zero. A zero-frame request is empty.
