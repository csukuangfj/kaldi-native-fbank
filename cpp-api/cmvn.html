CMVN

Full doxygen reference (auto-generated from the headers): C++ API doxygen

Header: kaldi-native-fbank/csrc/feature-cmvn.h

Semantics follow kaldi's transform/cmvn.cc exactly (same arithmetic and stats layout).

knf::MatrixF feats = ...;  // rows = frames

// full 2-row stats: row0 = [sums, count], row1 = [sumsq, (unused)]
knf::MatrixD stats = knf::ComputeCmvnStats(feats);

knf::CmvnOptions opts;          // norm_vars=false, reverse=false
knf::MatrixF out = knf::ApplyCmvn(stats, opts, feats);

// incremental
knf::CmvnAccumulator acc(feats.cols());
acc.Accumulate(feats);
const knf::MatrixD &s = acc.Stats();

Public Members

bool norm_vars = false

If true, normalize the variances as well: after subtracting the mean, each dimension is divided by its standard deviation.

Requires 2-row stats (kaldi apply-cmvn --norm-vars).

bool reverse = false

If true, undo cmvn instead of applying it: the mean is added back and, if norm_vars is true, the standard deviation is multiplied back (kaldi apply-cmvn --reverse).

class CmvnAccumulator

Incremental accumulator for speaker-level / streaming cmvn.

It always keeps the full 2-row layout (see InitCmvnStats()) and adds up weighted frames one by one, so stats can be collected over many utterances of the same speaker and normalized later with ApplyCmvn().

See also

AccCmvnStats, InitCmvnStats, ApplyCmvn

Used by:

Pipelines that collect speaker-level stats incrementally (e.g. accumulate all utterances of a speaker, then normalize).

void knf::InitCmvnStats(int32_t dim, MatrixD *stats)

Initialize cmvn stats to zeros in the FULL 2-row layout.

The output matrix stats is resized to 2 x (dim+1) and set to zero. Its layout matches kaldi's cmvn.ark format exactly:

\[\begin{split} \mathrm{stats} = \left( \begin{array}{cccc|c} S_1 & S_2 & \cdots & S_D & c \\ Q_1 & Q_2 & \cdots & Q_D & - \end{array} \right) \end{split}\]

Row 0 (above): columns 0 .. dim-1 hold the sums \( S_d = \sum_t x_t(d) \) of each feature dimension; the last column \( c \) holds the frame count (sum of weights).

Row 1 (below): columns 0 .. dim-1 hold the sums of squares \( Q_d = \sum_t x_t(d)^2 \); the last column is unused.

This is the form produced/consumed by AccCmvnStats(), ComputeCmvnStats() and ApplyCmvn() with norm_vars=true.

Note: ApplyCmvn() also accepts 1-row (mean-only) stats, where only row 0 above is present; this function, however, only produces the 2-row form used for accumulating both mean and variance.

knf::MatrixD stats;
knf::InitCmvnStats(39, &stats);  // stats: 2 x 40, all zeros

See also

AccCmvnStats, ComputeCmvnStats, ApplyCmvn

Parameters:

  • dim -- [in] Feature dimension of the frames that will be accumulated, e.g. 39 for 39-dim MFCC.

  • stats -- [out] The output stats matrix, resized to 2 x (dim+1).

void knf::AccCmvnStats(const float *feat, int32_t dim, float weight, MatrixD *stats)

Accumulate stats for one frame (kaldi AccCmvnStats, same op order).

The following updates are applied to stats, which must use the full 2-row layout (see InitCmvnStats()); with \( w = \) weight and \( x_d = \) feat[d]:

\[ c \mathrel{+}= w, \qquad S_d \mathrel{+}= x_d\, w, \qquad Q_d \mathrel{+}= x_d^2\, w \qquad (0 \le d < \mathrm{dim}) \]

knf::MatrixD stats;
knf::InitCmvnStats(dim, &stats);
for (int32_t t = 0; t < num_frames; ++t) {
knf::AccCmvnStats(feats.row(t).data(), dim, 1.0f, &stats);
}

See also

InitCmvnStats, ComputeCmvnStats, CmvnAccumulator::Add

Parameters:

  • feat -- [in] Pointer to one frame, a 1-D array of size dim.

  • dim -- [in] Feature dimension of the frame; must equal stats->cols() - 1.

  • weight -- [in] Weight of this frame, e.g. 1.0.

  • stats -- [inout] Stats to update; must use the full 2-row layout.

void knf::ApplyCmvn(const MatrixD &stats, const CmvnOptions &opts, MatrixF *feats)

Apply cmvn to feats in place (kaldi ApplyCmvn / ApplyCmvnReverse).

Let \( c = \mathrm{stats}(0, \mathrm{dim}) \) be the frame count, \( \mu_d = \mathrm{stats}(0, d) / c \) the mean and, when norm_vars is true, \( \sigma_d^2 = \mathrm{stats}(1, d) / c - \mu_d^2 \) the variance of dimension \( d \).

Forward (opts.reverse == false), applied to every frame \( x \):

\[ x_d \leftarrow x_d - \mu_d \]
and, if opts.norm_vars:
\[ x_d \leftarrow (x_d - \mu_d) / \sigma_d \]

Reverse (opts.reverse == true) undoes the normalization:

\[ x_d \leftarrow x_d + \mu_d \]
and, if opts.norm_vars:
\[ x_d \leftarrow x_d \cdot \sigma_d + \mu_d \]

Accepts 1-row (mean-only) or 2-row stats; requesting norm_vars with 1-row stats is an error (same as kaldi).

knf::MatrixD stats = knf::ComputeCmvnStats(feats);
knf::CmvnOptions opts;  // norm_vars=false, reverse=false
knf::ApplyCmvn(stats, opts, &feats);  // feats normalized in place

See also

ComputeCmvnStats, CmvnOptions, CmvnAccumulator

Parameters:

  • stats -- [in] 1-row or 2-row cmvn stats; see InitCmvnStats().

  • opts -- [in] Options: norm_vars (normalize variances), reverse (undo cmvn).

  • feats -- [inout] Feature matrix of size num_frames x dim; each row is normalized in place.

MatrixF knf::ApplyCmvn(const MatrixD &stats, const CmvnOptions &opts, const MatrixF &feats)

Convenience version of ApplyCmvn(): returns the normalized copy.

Same semantics as the in-place ApplyCmvn() above, but feats is left unchanged and a normalized copy is returned.

Parameters:

  • opts -- [in] Options: norm_vars (normalize variances), reverse (undo cmvn).

Returns:
