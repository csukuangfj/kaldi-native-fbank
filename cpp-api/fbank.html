struct FbankOptions

Options for computing filter-bank features.

This is kaldi's FbankOptions (src/feat/feature-fbank.h). It only includes things that can be done in a "stateless" way, i.e. it does not include energy max-normalization and it does not include delta computation.

bool use_energy = false

If true, append an extra dimension with energy to the filter banks.

float energy_floor = 0.0f

Floor on energy (absolute, not relative) in fbank computation.

Only makes a difference if use_energy is true; only necessary if frame_opts.dither is 0.0. Suggested values: 0.1 or 1.0.

bool raw_energy = true

If true, compute log energy before preemphasis and windowing; if false, compute it after preemphasis and windowing.

bool htk_compat = false

If true, put energy last (if using energy); if false, put energy first.

Warning: not sufficient to get HTK compatible features (need to change other parameters).

bool use_log_fbank = true

If true (default), produce log-filterbank; else linear.

bool use_log_floor = true

If true (default), use Kaldi's hard floor before the log, i.e.

\( \log(\max(e, \epsilon)) \). If false, use the additive guard \( \log(e + \epsilon) \), where \( e \) is the mel energy. NeMo models use the additive guard with eps = FLT_EPSILON / 2 (2^-24).

float eps = std::numeric_limits<float>::epsilon()

Value used by the log-zero guard selected by use_log_floor.

It defaults to FLT_EPSILON; NeMo models use FLT_EPSILON / 2 (2^-24, 5.9604644775390625e-08).

bool use_power = true

If true (default), use power in filterbank analysis; else magnitude.
