MatrixF knf::SpliceFrames(const MatrixF &feats, const SpliceOptions &opts)

Concatenate each frame with its left/right context neighbors.

This is kaldi's splice-feats (kaldi SpliceFrames in src/feat/feature-functions.cc), same arithmetic: for every frame index \( t \) the output row is

\[ y_t = [ x_{\max(0, t-L)}, \ldots, x_{\min(T-1, t+R)} ] \]

where \( L = \) opts.left_context, \( R = \) opts.right_context and \( T \) is the number of input frames. Edge frames are replicated: out-of-range indices clamp to the first/last frame. The output therefore has the same number of frames as the input and dim * (1 + L + R) dimensions.

knf::SpliceOptions opts;  // left=3, right=3 -> 7*D dims
knf::MatrixF spliced = knf::SpliceFrames(feats, opts);
