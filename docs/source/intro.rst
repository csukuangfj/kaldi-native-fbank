Introduction
============

kaldi-native-fbank computes acoustic features that are numerically
compatible with kaldi.  It is written in C++ and comes with Python bindings.

Feature building blocks
-----------------------

============================  ====================================================
Component                     Header
============================  ====================================================
MFCC                          :knf:`kaldi-native-fbank/csrc/feature-mfcc.h`
Fbank                         :knf:`kaldi-native-fbank/csrc/feature-fbank.h`
CMVN                          :knf:`kaldi-native-fbank/csrc/feature-cmvn.h`
============================  ====================================================

More components (splice, deltas, LDA transform, pitch) are being added; each
component ships with :knf:`golden test data <tests/data/feat_golden>` generated by kaldi binaries
(:knf:`tests/data/feat_golden`) and unit tests that compare against it
value-by-value.
